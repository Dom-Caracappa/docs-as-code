# Ubuntu Server Installation Guide

This guide walks you through installing Ubuntu Server for local development or production use.

---

## Download Ubuntu ISO

Go to [ubuntu.com/download/server](https://ubuntu.com/download/server)

## Installation Steps

1. Create bootable USB
2. Boot into the installer
3. Follow prompts
4. Set up SSH and user accounts
5. Done!
